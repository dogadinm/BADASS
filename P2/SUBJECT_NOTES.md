# P2 requirements extracted from the BADASS subject

- Build the first VXLAN network first in **static mode**, then in **dynamic multicast mode**.
- Use **VXLAN ID / VNI 10**.
- Create a bridge named **br0**.
- Ethernet interface names are free to choose.
- The subject's multicast example uses **239.1.1.1**, and explicitly says this value may be changed.
- Be able to inspect traffic between the two hosts and display the MAC address table on both routers.
- Submit under the root-level **P2** folder, with commented configuration files.
- Export the GNS3 project with ZIP compression including the base images and keep that file in the repository.
- Equipment names must be correct and consistent and contain one group member's login.
